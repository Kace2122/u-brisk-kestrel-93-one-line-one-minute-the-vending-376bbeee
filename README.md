One pickup line, 200 characters at most, as if a vending machine were flirting with a passing human.
`main.py` writes the pickup line to `/output/entry.txt` (deterministic, with a 1–200 char self-check).

Entry: "Are you a snack? Because I've been holding a cold drink and warm feelings for you all day — insert coin to continue."
